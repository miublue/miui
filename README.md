# MIUI

Miu's whimsical little GUI framework for Raylib projects.

I made this so i don't have to rewrite button logic everytime i make a new toy project.
Also because it's fun to implement things myself.

# Features

For now it only has the following:

* Simple themes
* Text (with left, center and right alignment)
* Buttons
* Text input fields

New features will be added as i need them (or whenever i feel like it).
